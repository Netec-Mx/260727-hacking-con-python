# Hacking con Python

Curso práctico para desarrolladores que enseña a construir herramientas básicas de hacking ético con Python: reconocimiento, automatización HTTP, networking y explotación controlada, priorizando buenas prácticas y uso responsable.

## Estructura

- `CapituloXX/README.md`: guía de laboratorio por capítulo.

## Lista de laboratorios

### Capítulo 1

- [primer script para recolección de datos](Capitulo01/README.md#primer-script-para-recolección-de-datos)
  - Descripción: Desarrollar un primer script en Python para la recolección de datos, aplicando la sintaxis, las variables, las funciones, el manejo de errores y las estructuras de datos revisadas en el capítulo.
  - Duración estimada: 24 min

### Capítulo 2

- [script de recolección pasiva con APIs públicas](Capitulo02/README.md#script-de-recolección-pasiva-con-apis-públicas)
  - Descripción: Construir un script de recolección pasiva que consulte APIs públicas y utilice servicios y bibliotecas de Python para tareas OSINT en un entorno controlado.
  - Duración estimada: 30 min

### Capítulo 3

- [automatizar consultas respetuosas y almacenar resultados](Capitulo03/README.md#automatizar-consultas-respetuosas-y-almacenar-resultados)
  - Descripción: Implementar una rutina automatizada de consultas con paginación, concurrencia controlada y delays, y almacenar los resultados recolectados de forma normalizada y respetuosa.
  - Duración estimada: 46 min

### Capítulo 4

- [herramienta de banner grabbing en Python](Capitulo04/README.md#herramienta-de-banner-grabbing-en-python)
  - Descripción: Desarrollar una herramienta de banner grabbing en Python que extraiga banners y cabeceras, permita interpretar los resultados y realice una clasificación básica de los servicios identificados.
  - Duración estimada: 46 min

### Capítulo 5

- [automatizar pruebas básicas contra un entorno vulnerable](Capitulo05/README.md#automatizar-pruebas-básicas-contra-un-entorno-vulnerable)
  - Descripción: Automatizar pruebas básicas mediante clientes HTTP en Python, utilizando requests, sesiones y manejo de cookies contra una aplicación web vulnerable en un entorno controlado.
  - Duración estimada: 46 min

### Capítulo 6

- [scripts de Scapy y rutinas SSH controladas](Capitulo06/README.md#scripts-de-scapy-y-rutinas-ssh-controladas)
  - Descripción: Crear scripts con Scapy para la generación y el análisis de paquetes, e implementar rutinas de automatización sobre SSH y conexiones seguras en un Practica  controlado.
  - Duración estimada: 46 min

### Capítulo 7

- [integración práctica con Metasploit/TOR](Capitulo07/README.md#integración-práctica-con-metasploittor)
  - Descripción: Integrar Python con Metasploit y TOR para ejecutar rutinas controladas, reutilizables y orientadas a prácticas de hacking ético.
  - Duración estimada: 46 min

### Capítulo 8

- [integración y entrega de un toolkit ético](Capitulo08/README.md#integración-y-entrega-de-un-toolkit-ético)
  - Descripción: Integrar las rutinas desarrolladas durante el curso y entregar un toolkit ético, aplicando una planificación definida, controles y permisos, una metodología segura y criterios de reporte y almacenamiento seguro de hallazgos.
  - Duración estimada: 43 min
